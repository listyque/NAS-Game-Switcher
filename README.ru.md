![Библиотека NGS с реальными играми](media/library.png)

NGS превращает собственную коллекцию игр на сервере в библиотеку для портативных ПК с Windows. Храните игры на NAS, скачивайте нужные на устройство и переключайтесь между игрой и управлением NGS. Сервер принадлежит вам. Игры в комплект не входят, аккаунты создаются на вашем сервере.

**Нет NAS? Начните локально.** Чистая установка открывает «Мои игры» без регистрации и сервера. Добавляйте папки игр или находите установленные игры из магазинов; обложки, фоны и описания загружаются напрямую из игровых источников и кешируются на устройстве. Библиотека, параметры запуска и история хранятся в SQLite. NAS можно подключить позже для скачивания, синхронизации профиля и серверных резервных копий.

## Возможности

- **Удобная библиотека:** управление геймпадом, тачем и мышью; плитки и подробные карточки; описания, обложки, фильтры, сортировка и избранное.
- **Контроль места:** игры в очереди резервируют пространство, загрузки поддерживают докачку и проверку содержимого, локальным папкам можно дать читаемые названия игр.
- **Игра на устройстве:** запуск скачанных игр и поддерживаемых локальных игр или записей из магазинов; экран игровой сессии показывает время и позволяет завершить игру.
- **Ввод без физической клавиатуры:** встроенная клавиатура с восемью видами, своими раскладками, темами, макросами, назначением клавиш на геймпад и тачпадами.
- **Оформление коллекции NAS:** отдельные каталогизаторы готовых игр и полных установочных комплектов с подбором оформления и массовым добавлением.
- **Управление приставкой:** компактный язычок открывает звук, яркость и другие быстрые настройки. Дополнительный NGS Input позволяет показывать клавиатуру и управление поверх поддерживаемых системных окон Windows. Верхнее меню можно настроить или отключить в опциях.
- **Свой профиль:** регистрация на вашем NAS, вход с другого устройства, синхронизация истории и резервные копии настроек. Статистику отдельной игры можно сбросить только на текущем устройстве.
- **Настройки под себя:** английский по умолчанию и русский в опциях; акцентные цвета, темы, масштаб и Production Mode для сокращения диагностического логирования.
- **Свой сервер:** Docker или пакет Synology SPK, подключение исходных папок только для чтения, раздельные права игрока и владельца, доступ через интернет по HTTPS без VPN.

## Клавиатура для портативного ПК

Обычная, компактная, разделённая на две половины, традиционная, геймпадная, полная, навигационная или NumPad — выбирайте подходящий вид. Настройте высоту и прозрачность, тему, создайте свои раскладки и макросы или управляйте курсором двумя тачпадами. Автопоказ реагирует на тап пальцем по редактируемому полю. Для игр с клавиатурным управлением есть готовые схемы геймпада и отдельные назначения клавиш.

![Встроенная клавиатура NGS](media/guide/keyboard-ru.png)

Клавиатура уже входит в NGS. Дополнительный компонент Windows **NGS Input** расширяет возможности показа управления, в том числе поверх «Пуска» и поддерживаемых системных окон. [Клавиатура, тачпады и геймпад подробно](docs/guide.ru.md#встроенная-клавиатура).

## Из папок NAS — в игровую библиотеку

Два встроенных каталогизатора работают с разными коллекциями: **готовыми играми** для скачивания и запуска и **установочными комплектами** для обычной установки на устройство. Выберите папку и исполняемый файл, найдите оформление, проверьте и опубликуйте. Массовое добавление обрабатывает однозначные совпадения, оставляя спорные для проверки. Для публикации нужны права владельца сервера; исходные папки NAS остаются доступны только для чтения.

![Каталогизатор готовых игр](media/guide/catalog-games-ru.png)

В [руководстве со скриншотами](docs/guide.ru.md) описаны оба каталогизатора, все пункты основного меню, шесть разделов настроек, клавиатура и быстрые панели. [English user guide](docs/guide.md). На скриншотах используется кешированное оформление реальных игр; примеры строк каталога и системных значений демонстрируют интерфейс.

## Начало работы

### Приставка или ПК с Windows

1. Скачайте **NGS-Setup-*.exe** из [Releases](https://github.com/listyque/NAS-Game-Switcher/releases).
2. Установите и запустите NGS. Если нужны элементы управления поверх игр, выберите дополнительный компонент **NGS Input**; Windows запросит разрешение на его установку.
3. **Локальная библиотека:** откройте **Мои игры**, добавьте папку игры или найдите установленные игры из магазинов. Аккаунт и сервер не нужны.
4. **NAS по желанию:** откройте **Настройки → Пользователи и аккаунт → Подключить NAS**, укажите адрес и зарегистрируйтесь либо войдите.
5. Для подключения к NAS по локальному HTTP один раз введите код из журнала приложения на NAS. При HTTPS с доверенным сертификатом этот шаг выполняется автоматически. После входа появятся «Каталог» и «Установщики».

**Требования:** Windows 11 x64. Python уже в комплекте. Также доступен portable ZIP: распакуйте всю папку и запустите `NGS.exe`. При переносе или обновлении сохраняйте папку `data`.

### Docker на NAS

1. Скачайте из Releases и распакуйте **NGS-Docker-0.1.0-preview.2.zip**.
2. Скопируйте `.env.example` в `.env` и укажите путь к своей папке игр.
3. Выполните `sh start.sh` и задайте пароль администратора.
4. Откройте `http://NAS-IP:8890/assets/ngs_launcher/client/` и следуйте инструкции подключения.

### Synology

1. Установите Container Manager на NAS с процессором x86-64 и DSM 7.2.1 или новее.
2. В **Package Center → Manual Install** («Центр пакетов → Ручная установка») выберите **NGS-Synology-0.1.0-preview.2.spk** из Releases.
3. Укажите папку игр, порт и пароль администратора. Для работы только в локальной сети домен можно не заполнять.
4. Откройте **NAS Game Switcher** в DSM и подключите клиент Windows.

Оба варианта начинают работу с пустой независимой базой и создают собственные ключи на вашем NAS. Личных данных и игр в пакетах нет. Полные инструкции, резервные копии и внешний HTTPS: **[Настройка сервера](server/README.ru.md)**. Домен можно подключить позднее; для работы через интернет и NGS, и админке нужен HTTPS с доверенным сертификатом.

## Сравнение с другими проектами

Эти проекты решают близкие задачи разными способами. «Описано» означает, что функция упоминается в документации по ссылке. Это сравнение возможностей, а не тест производительности.

| | NGS | [GameVault](https://gamevau.lt/docs/intro/) | [LANCommander](https://lancommander.app/) | [Gameyfin](https://gameyfin.org/) |
|---|---|---|---|---|
| Основной интерфейс | Лаунчер для Windows-приставок | Игровой клиент Windows | Собственный сервер распространения игр и лаунчер | Игровая библиотека в браузере |
| Свой сервер на NAS / Docker | Да | [Да](https://gamevau.lt/docs/server-docs/setup/synology-container-manager/) | [Да](https://lancommander.app/GettingStarted/) | [Да](https://gameyfin.org/installation/docker/) |
| Скачивание игр на локальный ПК | Да | Описано | Описано | Скачивание через браузер |
| Навигация геймпадом | Да | [Описана с версии 17](https://gamevau.lt/docs/client-docs/gui/) | Уточняйте в актуальной документации клиента | Зависит от браузера и устройства |
| Быстрые настройки приставки поверх игры | Дополнительный NGS Input | Уточняйте доступные интеграции | Уточняйте доступные интеграции | Вне задач браузерной библиотеки |
| Установка на Synology | Отдельный SPK в статусе preview и Docker | Официальная инструкция для Container Manager | Через Docker | Через Docker |
| Состояние проекта | Ранняя версия, проверка на устройствах продолжается | См. страницу проекта | См. страницу проекта | См. страницу проекта |

Выбирайте подходящий для своей коллекции способ работы. NGS сосредоточен на интерфейсе для приставки, локальном запуске и управлении вокруг игры. У альтернатив свои сильные стороны и сложившиеся экосистемы.

## Текущие ограничения

Проект активно разрабатывается. Игры, другие лаунчеры, античиты и эксклюзивный полноэкранный режим по-разному работают с фокусом и оверлеями. Показ оверлея поверх абсолютно любой игры не гарантируется. Тач, установленный UIAccess и пакет DSM требуют проверки на реальных устройствах; автоматические тесты её не заменяют. Скриншоты не подтверждают совместимость с каждой показанной игрой.

Дополнительный компонент ввода пока использует локальный сертификат издателя проекта: при установке Windows запрашивает доверие этому издателю. Устанавливайте релизные файлы из этого репозитория. Не открывайте в интернет внутренние порты TACTIC и PostgreSQL. Настройка HTTPS-шлюза и проверки прав владельца описана в инструкции сервера.

## Сборка из исходников

Для Windows используются **Python 3.13 x64, MSVC, Nuitka 4.1.1 и PySide6 6.11.2**. Установите зависимости из `requirements-build.txt`. Выполните `python -m tools.compile_translations`, соберите NGS Input командой `python -m tools.build_input_host` и подпишите его приложенными скриптами, затем выполните `python -m tools.build_windows`. Установщик собирается командой `python -m tools.build_installer <portable-folder> --compiler <makensis.exe>`. Для подписи нужен собственный сертификат; до сборки укажите его отпечаток в `ngs/input_host.py` и `tools/launch_input_install.ps1`. Закрытых ключей в репозитории нет.

Сервер собирается из `server/Dockerfile`. Команда `python -m server.package_bundle` создаёт Docker-комплект для установки с загрузкой образов. Для автономного SPK экспортируйте три образа из Compose в `server/images/ngs-images.tar`, затем выполните `python -m server.build_dsm`. Тесты находятся в `tests`: проверки Qt используют фоновый режим offscreen, а сценарии установки DSM проверяются в Linux от обычного пользователя. Перед пересборкой любого компонента Windows компилируйте переводы.
