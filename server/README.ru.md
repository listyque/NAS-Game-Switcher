# Сервер NGS · Предварительная версия

Ваша игровая библиотека на собственном NAS. Клиенты Windows скачивают игры по HTTP(S), исходные папки подключаются только для чтения. Настраивать SMB на приставке не нужно.

## Docker

1. Установите Docker Engine и Docker Compose на NAS или ПК с Linux и процессором x86-64.
2. Распакуйте **NGS-Docker-0.1.0-preview.2.zip** в постоянную папку.
3. Скопируйте `.env.example` в `.env`. В `NGS_GAMES_PATH` укажите существующую папку игр, при необходимости задайте `NGS_INSTALLERS_PATH` для установщиков. Чтобы сначала попробовать NGS без коллекции, оставьте значения с пустыми папками по умолчанию.
4. Выполните `sh start.sh` в этой папке и задайте пароль администратора.
5. Дождитесь состояния healthy у сервисов в `docker compose ps`.
6. Откройте `http://NAS-IP:8890/assets/ngs_launcher/client/`.
7. Установите клиент Windows из GitHub Releases. В **Settings → Account** («Настройки → Аккаунт») укажите `http://NAS-IP:8890/tactic`.
8. Для первого локального подключения скопируйте **NGS local pairing code** из `docker compose logs app` в NGS. Зарегистрируйте профиль игрока или войдите.

Владелец сервера — **admin** с выбранным вами паролем. Регистрация создаёт аккаунты игроков и не даёт прав на изменение каталога или администрирование. Добавляйте игры через каталогизатор из аккаунта владельца. Для отдельного входа в админку TACTIC также используются `admin` и пароль, выбранный при установке.

Комплект скачивает `ghcr.io/listyque/nas-game-switcher/server:0.1.0-preview.2`, PostgreSQL 16.15 и Caddy 2.11.7. Сохраняйте папку установки, `.env`, `data`, `secrets` и `backups`. Не публикуйте эти файлы. Для разных установок используйте разные имена проектов Compose.

## Synology DSM

1. Нужен **NAS x86-64**, **DSM 7.2.1+** и **Container Manager 20.10.23-1437+**.
2. В «Центре пакетов» выберите **Manual Install** («Ручная установка») и файл **NGS-Synology-0.1.0-preview.2.spk**.
3. Укажите папку игр, свободный порт и пароль администратора. Папка установщиков необязательна, домен можно оставить пустым.
4. Дождитесь запуска пакета и откройте **NAS Game Switcher** в DSM.
5. Установите NGS на Windows, введите показанный адрес сервера и скопируйте код подключения из журнала контейнера app в Container Manager. Зарегистрируйтесь или войдите.

SPK содержит серверные образы для установки без их скачивания и использует Docker Project Worker Synology. Для установки не нужны SSH и команды Docker. Папки игр остаются доступными только для чтения. Установка на настоящем DSM пока не проверена; это предварительная версия пакета.

## Доступ через интернет без VPN

Для локальной сети домен необязателен. Настройте его перед включением внешнего доступа:

1. Направьте домен или DDNS-имя на свой публичный IP. В `.env` задайте `NGS_PUBLIC_DOMAIN`, указав только имя хоста; на DSM введите его при настройке пакета.
2. Пробросьте **внешний порт 80 → порт NAS 8088** и **внешний порт 443 → порт NAS 8448** либо выбранные вами порты шлюза. Не пробрасывайте внутренний порт NGS и PostgreSQL. Ограничьте доступ к внутреннему порту NGS доверенной локальной сетью.
3. Снова выполните `sh start.sh`. Caddy получит доверенный HTTPS-сертификат. Для проверки сертификата внешние порты 80/443 должны быть доступны; при CGNAT потребуется отдельная доступная извне точка входа.
4. В NGS используйте `https://your-domain/tactic`. Тот же домен открывает страницу загрузки и админку.

Для подключений через интернет требуется HTTPS. Шлюз проверяет профиль владельца NGS перед отдельным входом в TACTIC, отклоняет межсайтовые запросы к админке и защищает доступ к игровым файлам авторизацией игрока. Локальное подключение по HTTP с кодом проверяет подлинность сервера, но не шифрует весь HTTP-трафик; используйте его только в доверенной сети. Не отключайте проверку сертификата.

## Обновления и резервные копии

Перед обновлением Docker выполните `sh backup.sh` и сохраните полученную приватную резервную копию в безопасном месте. Измените тег образа в `compose.yaml`, затем запустите `sh start.sh`. Не удаляйте тома с данными. На DSM устанавливайте новый публичный SPK поверх существующего пакета: папки, пароли и настройки сохраняются. Требуется совпадающий публичный bootstrap; частные базы разработки намеренно не принимаются. Перед запуском изменённого серверного плагина NGS сохраняет обе базы в `backups/before-update-*`; при ошибке резервного копирования обновление останавливается.

Клиент Windows использует подписанные манифесты официальных релизов GitHub и проверяет хэши пакетов. Обновления клиента не зависят от конкретного NAS. Для сборки сервера из исходников выполните в этой папке `docker build -t ghcr.io/listyque/nas-game-switcher/server:0.1.0-preview.2 .`. Dockerfile скачивает закреплённый коммит TACTIC и проверяет его контрольную сумму; личная база не нужна.
