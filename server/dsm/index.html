Download NGS for WindowsServer administration

In NGS open Settings → Account, enter this server address, then create your profile or sign in.

For the first local HTTP connection, copy the NGS local pairing code from the app container log in Container Manager into NGS. HTTPS with a trusted certificate does not require this step.

Server owner: admin and the password chosen during NAS installation. Player profiles cannot edit the catalog. Internet administration requires the owner profile before the separate TACTIC login.

For Internet access, configure a domain and trusted HTTPS first. Forward only HTTPS and the certificate challenge port; never expose PostgreSQL or the internal NGS port. You can set up the domain later.
