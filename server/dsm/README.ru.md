# Пакет Synology · Предварительная версия

Установите SPK через **«Центр пакетов → Ручная установка»** (Package Center → Manual Install). Нужен NAS x86-64, DSM 7.2.1+ и Container Manager 20.10.23-1437+.

Выберите папку игр, которая будет подключена только для чтения, свободный порт сервера и пароль администратора. Для локальной сети оставьте домен пустым. После запуска откройте NAS Game Switcher в DSM и следуйте инструкции подключения Windows. Код локального подключения находится в журнале контейнера app в Container Manager.

Устанавливайте обновления поверх существующего публичного пакета. Данные, пароли и настройки сохраняются. Неизвестные базы и частные базы разработки не принимаются. Установка на настоящем DSM пока не проверена. Полные инструкции, HTTPS и резервное копирование описаны в [русской инструкции сервера](../README.ru.md).
