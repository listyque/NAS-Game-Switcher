# Synology package · Preview

Install the SPK with Package Center → Manual Install. Requires an x86-64 NAS, DSM 7.2.1+ and Container Manager 20.10.23-1437+.

Choose a read-only game source, an unused server port and an admin password. Leave the domain blank for LAN use. Open NAS Game Switcher in DSM after startup, then follow the Windows connection instructions. The local pairing code is in the app container log in Container Manager.

Install updates over the existing public package. Persistent data, passwords and settings are retained. Unknown or private development databases are rejected. Physical DSM installation remains unverified; see the server README for the complete setup, HTTPS and backup instructions.
